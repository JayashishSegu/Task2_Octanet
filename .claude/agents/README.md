# Nextraise Marketing Agents Pack (for Claude Code)
5 parallel subagents from zubair-trabzada/ai-marketing-claude (MIT):
market-strategy, market-content, market-conversion, market-technical, market-competitive

## Install
Copy the .md files into your project's `.claude/agents/` (or `~/.claude/agents/` for global).
Then in Claude Code: "Run a full marketing audit of nextraise.ai" — Claude spawns all 5 in parallel.

## Note for claude.ai
claude.ai doesn't support installable agents — skills are the equivalent there.
Your `nextraise-growth-command` skill IS your agent/orchestrator on claude.ai.
